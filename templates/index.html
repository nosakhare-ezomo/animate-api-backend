The unofficial Nkiri REST API

Drop this headless scraper into any website. Search movies, fetch metadata, and extract direct download links in milliseconds. Always live, never cached.

Systems Operational
GET

/api/search

Search for movies and TV shows across the Nkiri database. Call this endpoint when the user types in your search box.

Parameters

  • q (required) The search query (e.g., avengers).
  • page (optional) Page number for pagination. Default is 1.
// Request: /api/search?q=avengers
{
  "results": [
    {
      "title": "Avengers Endgame",
      "url": "https://thenkiri.com.ng/avengers-endgame/",
      "thumbnail": "https://..."
    }
  ],
  "count": 10,
  "query": "avengers"
}
GET

/api/movie

Fetch detailed metadata for a specific movie page, including high-res posters, descriptions, and release details.

Parameters

  • url (required) The full Nkiri URL for the movie, returned from the search endpoint.
// Request: /api/movie?url=https://thenkiri.com.ng/avengers-endgame/
{
  "title": "Avengers Endgame",
  "url": "https://thenkiri.com.ng/avengers-endgame/",
  "thumbnail": "https://...",
  "description": "After the devastating events...",
  "details": {
    "year": "2019",
    "genre": "Action, Adventure",
    "size": "1.2GB"
  }
}
GET

/api/download

Core API

Extract direct, un-obfuscated download links. Call this ONLY when a user clicks the Download button. The API scrapes in real-time to bypass rate limits and ensure links never expire.

Parameters

  • url (required) The full Nkiri URL for the movie.
// Request: /api/download?url=https://thenkiri.com.ng/avengers/
{
  "title": "Avengers Endgame",
  "url": "https://thenkiri.com.ng/avengers/",
  "links": [
    {
      "label": "Download 720p",
      "url": "https://mediafire.com/...",
      "host": "mediafire.com"
    },
    {
      "label": "Download 1080p",
      "url": "https://gofile.io/...",
      "host": "gofile.io"
    }
  ],
  "count": 2
}
